# Cucumber Breeder Dashboard

Static multi-trait dashboard for VeggieVision cucumber exports. It runs entirely in the browser and can be hosted with GitHub Pages.

## Data privacy

The repository contains no trial CSV. Users choose a CSV locally; JavaScript processes it in the browser. The selected data is not uploaded or retained by this site.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
